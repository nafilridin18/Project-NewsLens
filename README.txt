Newslensbd | কামিং সুন প্রজেক্ট
==============================

পরিচিতি
-------
Newslensbd-এর অফিসিয়াল লঞ্চের আগে ব্যবহারের জন্য একটি কামিং সুন (Coming Soon) ল্যান্ডিং পেজ।
এতে লঞ্চের কাউন্টডাউন, দর্শকের ইমেইল সংগ্রহের ফর্ম এবং সোশ্যাল মিডিয়া লিংকের ব্যবস্থা রয়েছে।

প্রযুক্তিগত প্রয়োজনীয়তা
------------------------
- PHP সমর্থিত ওয়েব হোস্টিং (ইমেইল সংগ্রহের জন্য)
- Apache বা LiteSpeed সার্ভার (data ফোল্ডারের সুরক্ষার জন্য .htaccess সমর্থন)

ফাইল ও ফোল্ডারের গঠন
---------------------
index.html            মূল ওয়েব পেজ
subscribe.php         ইমেইল গ্রহণ ও সংরক্ষণের স্ক্রিপ্ট
assets/css/style.css  পেজের ডিজাইন
assets/js/main.js     কাউন্টডাউন ও ইমেইল ফর্মের স্ক্রিপ্ট
assets/img/           লোগো, ফেভিকন ও পার্টনার লোগো
data/                 সংগৃহীত ইমেইলের ফোল্ডার (.htaccess দ্বারা সুরক্ষিত)

ডেপ্লয়মেন্ট
-----------
১. প্রজেক্টের সব ফাইল ও ফোল্ডার হোস্টিংয়ের public_html ডিরেক্টরিতে আপলোড করুন।
   আপলোড FTP ক্লায়েন্ট অথবা cPanel File Manager (ZIP আপলোড করে Extract) দিয়ে করা যাবে।
২. আপলোড শেষে ডোমেইনে প্রবেশ করে পেজটি সঠিকভাবে প্রদর্শিত হচ্ছে কি না যাচাই করুন।
৩. ইমেইল ফর্মে একটি পরীক্ষামূলক ঠিকানা জমা দিয়ে নিশ্চিত করুন যে সংরক্ষণ কাজ করছে।

কনফিগারেশন
----------
লঞ্চের তারিখ পরিবর্তন
  assets/js/main.js ফাইলের শুরুতে থাকা LAUNCH_DATE ভ্যারিয়েবলের মান পরিবর্তন করুন।
  ফরম্যাট: YYYY-MM-DDTHH:MM:SS+06:00
  উদাহরণ: "2026-10-23T00:00:00+06:00"
  (+06:00 বাংলাদেশ স্ট্যান্ডার্ড সময় নির্দেশ করে। নির্ধারিত সময় পার হলে কাউন্টডাউন স্বয়ংক্রিয়ভাবে "আজই লঞ্চ" বার্তা দেখাবে।)

কাউন্টডাউনের সময়সীমা
  একই ফাইলের WINDOW_DAYS ভ্যারিয়েবল অগ্রগতির বারের মোট দিন নির্ধারণ করে।

সোশ্যাল মিডিয়া লিংক
  index.html ফাইলের nav class="social" অংশে প্রতিটি href="#" এর স্থলে সংশ্লিষ্ট পেজের পূর্ণ URL বসান।
  লিংক নির্ধারণ না করা পর্যন্ত বাটনগুলো পেজে প্রদর্শিত হবে না।

ওপেন গ্রাফ ছবি (সোশ্যাল শেয়ার প্রিভিউ)
  index.html ফাইলের og:image মেটা ট্যাগে ছবির পূর্ণ URL দিন।
  উদাহরণ: https://আপনার-ডোমেইন/assets/img/logo.png

সংগৃহীত ইমেইল ব্যবস্থাপনা
-------------------------
- জমা হওয়া ইমেইল data/subscribers.php ফাইলে সংরক্ষিত হয়। ফাইলটি প্রথম ইমেইল জমা হওয়ার সময় স্বয়ংক্রিয়ভাবে তৈরি হয়।
- ফাইলটি ডাউনলোড করতে FTP বা cPanel File Manager ব্যবহার করুন। ডাউনলোডের পর Notepad বা Excel-এ খুললে
  email ও subscribed_at কলামসহ তালিকা দেখা যাবে।
- ফাইলের প্রথম লাইনে প্রতিরক্ষামূলক কোড থাকায় এবং data ফোল্ডারে প্রবেশাধিকার বন্ধ থাকায়
  ব্রাউজারের মাধ্যমে এই তথ্য দেখা সম্ভব নয়।
- একই ইমেইল একাধিকবার জমা দিলে তা শুধু একবারই সংরক্ষিত হয়।

ইমেইল সংগ্রহ বন্ধ করা
  ইমেইল সংগ্রহ প্রয়োজন না হলে index.html থেকে form class="notify" অংশ এবং সার্ভার থেকে subscribe.php ফাইলটি মুছে ফেলুন।

নিরাপত্তা
---------
- ফর্মে স্প্যাম বট প্রতিরোধের জন্য একটি লুকানো ঘর (honeypot) রয়েছে। এটি মুছে ফেলবেন না।
- সার্ভারে data ফোল্ডারের .htaccess ফাইলটি অবশ্যই রাখতে হবে।
- FTP পাসওয়ার্ড অন্য কারও সঙ্গে ভাগ করবেন না এবং ডেপ্লয়মেন্টের পর নিয়মিত পরিবর্তন করুন।
